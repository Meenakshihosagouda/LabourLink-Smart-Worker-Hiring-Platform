# LabourLink – A Smart Worker Hiring Platform
LabourLink is a web-based service marketplace platform developed using Python and Django. The platform connects clients with workers and contractors for services such as plumbing, electrical work, carpentry, and other maintenance tasks.

## Features
- Multi-role system for Clients, Workers, and Contractors
- Service search and booking system
- Worker recommendation based on ratings and experience
- Individual and bulk hiring support
- Chatbot assistant for user support
- Job management system
- Ratings and reviews
- User-friendly web interface

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
